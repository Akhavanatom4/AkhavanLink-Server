AkhavanLink — شبکهٔ LAN مجازی برای گیمرها
ساخته‌شده توسط علیرضا اخوان   (Created by Alireza Akhavan)
==========================================================

نصب لازم نیست. این پوشه رو هر جا خواستی (مثلاً Desktop) Extract کن و AkhavanLink.exe رو اجرا کن.


شروع سریع
---------
1) AkhavanLink.exe رو اجرا کن. ویندوز اجازهٔ Administrator می‌خواد -> Yes بزن.
   (اگه SmartScreen نوشت "Windows protected your PC": روی More info بزن و بعد Run anyway.
    برنامه امضای دیجیتالِ پولی نداره، برای همین ویندوز هشدار می‌ده.)
2) بار اول، درایور کارت شبکهٔ مجازی (Wintun) خودش نصب می‌شه. چند ثانیه صبر کن.
3) اگه آدرس سرور از قبل تنظیم نشده: دکمهٔ تنظیمات -> "آدرس سرور" رو بذار -> "تست سرور" -> ذخیره.
4) "نام شبکه" و "رمز شبکه" رو با دوستات یکی کن و روی دکمهٔ بزرگ اتصال بزن.
5) آی‌پی مجازی خودت وسط صفحه‌ست و آی‌پی بقیه توی لیست "بازیکن‌ها" (کلیک = کپی).


بازی کردن
---------
* میزبان بازی رو می‌سازه و بقیه با آی‌پی مجازی میزبان وصل می‌شن (Direct IP / Join by IP / Connect to IP).
* بازی‌هایی که تب LAN دارن معمولاً خودشون شبکه رو پیدا می‌کنن (کارت AkhavanLink متریک ۱ می‌گیره تا بازی‌ها اول سراغ اون برن).
* تست سریع ارتباط: توی CMD بنویس   ping 10.77.0.2   (به‌جای اون آی‌پی دوستت).
* برنامه رو تا آخر بازی باز نگه دار. بستن پنجره = قطع شدن از شبکه.


اگه کار نکرد
------------
* "تست سرور" توی تنظیمات قرمز شد: آدرس سرور رو چک کن. صفحهٔ اصلی سرور (آدرس رو توی مرورگر باز کن) باید "AkhavanLink" رو نشون بده.
* خطای گواهی امنیتی (TLS): تاریخ و ساعت ویندوز رو درست کن.
* خطای رمز اشتباه: نام شبکه و رمز باید با بقیه دقیقاً یکی باشه. (نام شبکه به حروف بزرگ/کوچک حساس نیست.)
* "wintun.dll پیدا نشد": دکمهٔ "دانلود خودکار" رو بزن، یا فایل wintun.dll رو از wintun.net بگیر و کنار AkhavanLink.exe بذار.
* آنتی‌ویروس درایور یا برنامه رو بلاک کرد: AkhavanLink.exe و پوشهٔ برنامه رو توی Exclusions بذار.
* بازی دوستت رو نمی‌بینه: از Direct IP استفاده کن. گزینهٔ "اجازهٔ ترافیک شبکهٔ مجازی در فایروال" توی تنظیمات باید روشن باشه.
* اگه VPN/پروکسی داری و سرور باز نمی‌شه: توی تنظیمات -> پیشرفته، آدرس پروکسی HTTP رو بذار (مثلاً http://127.0.0.1:10809).
* گزارش‌ها: پوشهٔ logs کنار برنامه  (یا دکمهٔ "گزارش‌ها" توی برنامه).
* تشخیص خودکار مشکل: توی CMD بزن   AkhavanLink.exe --selftest   و فایل selftest.txt رو بفرست.


تنظیمات فایل config.json
------------------------
serverUrl    آدرس سرور (مثلاً my-app.deplexo.app)
network      نام شبکه            password   رمز شبکه
nickname     نام نمایشی          accessKey  کلید دسترسی سرور (اگه روی سرور ACCESS_KEY گذاشتی)
firewall     اجازهٔ ترافیک شبکهٔ مجازی در فایروال ویندوز (true/false)
proxy        پروکسی HTTP اختیاری  mtu        پیش‌فرض 1400
(همهٔ اینا از توی خود برنامه هم قابل تغییره.)
